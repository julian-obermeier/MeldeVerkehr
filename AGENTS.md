# Agent Instructions

Vor Änderungen am Code:

1. `docs/MASTER_PROMPT.md` lesen.
2. `docs/SPECIFICATION.md` lesen.
3. `PROJECT_STATUS.md` lesen.

Verbindliche Regeln:

- Shared-Hosting-Kompatibilität erhalten.
- Keine privaten Beweise öffentlich ausliefern.
- Permission- und Ownership-Checks niemals umgehen.
- Historische Vorgangs- und Tatbestandsversionen niemals still überschreiben.
- Keine Secrets committen.
- Schemaänderungen nur über Migrationen.
- Kritische Aktionen auditieren.
- KI-Ausgaben als Vorschläge behandeln; Nutzerfreigabe bleibt erforderlich.
- Tests vor Abschluss einer Phase ausführen.
- `PROJECT_STATUS.md` nach wesentlichen Änderungen aktualisieren.
- Nutzerrelevante Änderungen in `CHANGELOG.md` aufnehmen.
- Keine Funktion als fertig markieren, wenn nur UI/Platzhalter existieren.
